# 📊 Data Analytics Project

## 📌 Overview

This project demonstrates an end-to-end data analytics workflow, starting from raw data processing to business insight generation. The analysis was performed using **Python**, **MySQL**, and **Power BI** to clean, analyze, visualize, and report meaningful insights from the dataset.

---

## 📂 Dataset

The project uses a structured dataset for analytical purposes. The data is explored, cleaned, analyzed using SQL, and visualized through an interactive Power BI dashboard.

---

## 🛠️ Tech Stack

- **Python**
  - Pandas
  - NumPy
  - Matplotlib
  - Seaborn

- **MySQL**

- **Power BI**

- **Jupyter Notebook**

---

## 🚀 Project Workflow

### 1. Data Loading
- Imported the dataset into Python.
- Explored data structure and data types.

### 2. Data Cleaning
- Handled missing values.
- Removed duplicate records.
- Corrected inconsistent data.
- Prepared the dataset for analysis.

### 3. Exploratory Data Analysis (EDA)
- Performed statistical analysis.
- Identified trends and patterns.
- Created visualizations to understand the data.

### 4. SQL Analysis
- Loaded the cleaned dataset into MySQL.
- Executed SQL queries to extract business insights using filtering, grouping, aggregation, and joins.

### 5. Power BI Dashboard
Designed an interactive dashboard featuring:
- Key Performance Indicators (KPIs)
- Trend Analysis
- Category-wise Insights
- Interactive Filters
- Business Visualizations

### 6. Report Generation
Compiled the analysis into a report summarizing key findings, insights, and recommendations.

## ▶️ How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/Data-Analytics-Project.git
```

2. Install the required Python libraries.

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy pymysql
```

3. Open the Jupyter Notebook and run the analysis notebooks.

4. Import the cleaned dataset into MySQL and execute the SQL queries.

5. Open the `.pbix` file in Power BI Desktop to explore the dashboard.
